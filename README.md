# Machine Learning, Deep Learning & Analytics Portfolio

A practical collection of machine learning algorithms, unsupervised clustering, customer segmentation, predictive modeling, and business intelligence dashboards.

---

## 📌 Project Overview

This repository demonstrates end-to-end data science workflows ranging from exploratory data analysis and customer behavioral modeling to supervised classification and interactive BI reporting.

### 1. Classification & Predictive Modeling
- **Customer Churn Prediction (`exited prediction.ipynb`)**:
  - Predicts customer exit/attrition behavior using feature preprocessing, exploratory data analysis, and binary classification techniques.
- **Purchase Intent Prediction (`purchase pridiction.ipynb`)**:
  - Classifies user conversion likelihood based on user behavior and demographic signals.
- **Decision Trees & Ensembles (`decision tree and random forest classifier .ipynb`)**:
  - Implements and compares single decision trees against Random Forest ensemble classifiers, evaluating metrics like accuracy, precision, recall, and ROC-AUC.

### 2. Unsupervised Learning & Segmentation
- **Customer Segmentation (`Matrices and Customer Segmentation.ipynb`)**:
  - Groups customers into actionable behavioral clusters using feature matrices, distance metrics, and dimensionality analysis.
- **Hierarchical Clustering (`Hierarchical clustering .ipynb`)**:
  - Implements agglomerative hierarchical clustering, constructs dendrograms to identify natural groupings, and analyzes cluster linkage methods.

### 3. Data Visualization & Business Intelligence
- **Statistical Data Visualization (`Seaborn and Matplotlib.ipynb`)**:
  - Comprehensive exploratory data analysis (EDA) scripts demonstrating distributions, heatmaps, categorical plots, and trend line visualization.
- **Human Resources Dashboard (`HR ANALYSIS.pbix`)**:
  - Interactive Power BI report tracking workforce metrics, attrition drivers, departmental distributions, and employee performance KPIs.
